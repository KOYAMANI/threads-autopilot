# Cloudflare処理国の申告候補

2026-09-08にユーザーへ確認し、Metaの申請下書きへ入力・保存した一覧。アプリレビュー自体は未提出。

現在のCloudflare Workersは処理地域を固定していません。以下は公開ネットワークの国・地域とDeveloper Platformの再委託先（EEAを含む）から、処理が発生し得る範囲として整理した134か国・地域です。各国でこのアプリのデータが実際に処理されたという実測記録ではありません。Cloudflare China Networkは別契約のため含めていません。

根拠:
- [Cloudflare network](https://www.cloudflare.com/network/)
- [Workers placement](https://developers.cloudflare.com/workers/configuration/placement/)
- [Cloudflare subprocessors](https://www.cloudflare.com/gdpr/subprocessors/cloudflare-services/)
- [China Network](https://developers.cloudflare.com/china-network/)

処理国欄が「実際に処理済みの国」だけを要求する場合、この候補をそのまま使わずCloudflareへ確認が必要です。自動承認レビューの確認要求に対し、ユーザーが「想定は日本だけど任せる」と回答。利用者の所在地とは異なることを説明して入力しました。
