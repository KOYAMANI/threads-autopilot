## 採用した表示・操作変更
- 既存の紫トークンを使用。端末追従／ライト／ダークの端末単位切替。ダーク時の固定操作部も同じ配色。
- 設定を項目別のリストにし、PCには項目ナビを配置。APIキーの登録状態、メール／プッシュ状態を一覧表示。
- AccountsCard / AiKeyCard / GoogleSheetsCard / NotificationCard / LinksCard / PasswordCard / LicenseCard / DangerCardの既存フォームと保存処理を維持。自動保存への一括変更は採用しない。
- スマホの参考投稿検索・並べ替え・ページ送りを開く導線、自分で本文を書く導線を維持・復元。
- シートをbodyへportal表示し、固定ナビとの重なりを解消。掴み部分だけでドラッグし、本文スクロール・文字選択と分離。フォーカスをシート内に保持し、Esc・閉じるで元へ戻す。
- visualViewportに合わせてシートを調整。長文はAutoTextareaで高さを伸ばし、入力中の固定操作は通常フローへ移す。
- ホーム・キュー・分析・作成・自動運用・設定の既存ルートと操作を維持。
