# セキュリティ改善とGoogle連携の実装記録

2026-09-07。元のプロジェクトへ反映し、ローカルの `http://localhost:5173/app/settings` で表示を確認した。本番デプロイと実Googleアカウントの接続は未実施。

## 実装

- AIキーをサーバー暗号化保存に統一。旧端末キーを削除し、利用者切替でキャッシュ・通信・画面状態を破棄。
- Google OAuth、本人の管理表の自動作成、約1時間ごとの定期書き出し、再連携・解除・管理表の復旧操作を追加。秘密の列は書き出さない。
- 定期処理の全件登録・継続カーソルとCloudflare Queuesへの分配を追加。
- パスワード再設定の競合、共有端末のPush、APIサイズ・回数制限、ブラウザのセキュリティヘッダを改善。
- React Routerを7.18.3へ更新。ログイン成功時の二重遷移も実ブラウザで発見し修正。
- メンテナンス停止、DBエクスポートスクリプト、復旧手順を追加。ローカルマイグレーション0004を適用済み。

## 有効化・一般公開の前に残る作業

Google CloudのOAuthクライアント設定と実際の本人同意、Cloudflareの本番DB・Queue・Secrets・公開URL設定が必要。実Google APIの作成・定期更新、1,000人の本番負荷、クラウドDBと暗号鍵を使った災害復旧、管理者MFA・アクセス制御の設定は今回のローカル試験に含まない。

スプシはアプリからの一方向の書き出しで、セル編集をアプリへ戻す機能はない。独立バックアップの日次実行、保存先の暗号化・世代管理、鍵ローテーションも運用設定・追加作業が必要。今回の結果を漏洩ゼロ・データ消失ゼロ・1,000人の性能保証として扱わない。

設定方法は [Google連携](google-sheets.md)、公開と復旧は [本番運用](production-security.md) を参照。以前の [セキュリティレビュー](security-review-2026-09-07.md) は修正前の監査記録として保持する。
