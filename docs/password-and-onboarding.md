# ログイン・初回登録・パスワード変更

## 初回登録

1. 管理者が既存の `npm run licenses` 管理CLIで生徒ごとにライセンスキーを発行する。管理秘密鍵を生徒に渡さない。
2. 生徒に本番 `/login?mode=register` と本人用のライセンスキーを渡す。
3. 生徒が自分のメールアドレスと8〜200文字のパスワードを登録する。
4. 自分のThreadsアカウントとAIを接続する。

既存ユーザーは再登録せずログインする。ライセンスは一人につき一つ。Threads未接続でもホームと設定は開ける。

## パスワード変更

設定 → ログインとセキュリティ → パスワードを変更。
現在のパスワード、新しいパスワード、確認入力が必要。成功時は全端末のセッションとプッシュ購読を失効させ、未使用の再設定リンクも失効させる。新しいパスワードでログインし直す。本人の実際のパスワードは開発・デプロイ作業では変更しない。

API: `POST /api/auth/password`。ログインとCSRF検証が必須。ユーザーIDはセッションから決定する。15分で5回の試行制限。パスワードはソルト付きハッシュで保存し、旧ハッシュを条件にした更新と関連データの失効をD1のバッチトランザクションで実施する。同時変更が競合した場合は一方のみ成功する。

## デザイン

PCは左サイドバー、指標4列、グラフ2列、作成画面2列。スマートフォンは下部ナビゲーションと縦並び。設定は4カテゴリ。トップ投稿は10件ずつページ表示する。BlackTwistの分析の整理とTypefullyの余白を参考に、既存データと機能を配置し直した。ベスト投稿時間など未実装の分析指標は追加していない。
