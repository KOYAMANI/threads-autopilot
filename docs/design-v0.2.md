# Threads オートパイロット 設計書 v0.2（ウェブアプリ版 / 2026-08-31）

## 1. コンセプト

Threadsアカウントを「見る→作る→出す→学ぶ」まで1つの画面で回すウェブアプリ。
最大の特徴は**オートパイロット**：投稿の結果を次の投稿に反映し続ける学習ループ。

- 買い切り（ライセンスキー方式）
- AIは買い手のキー（OpenRouter / Gemini無料枠）で動く＝こちらの従量費ゼロ
- ホスティングはCloudflare無料枠（商用可）＝固定費ほぼゼロ

---

## 2. アーキテクチャ

```
[ブラウザ: React SPA（PWA, スマホ最適化）]
        │ HTTPS
[Cloudflare Worker]
   ├ /api/*        認証・アカウント・投稿・キュー・生成
   ├ 静的配信       SPA本体
   └ Cron Triggers
        ├ */5 * * * *   キュー実行（期日到来分を投稿、ツリーのコメントも順に）
        ├ 0 * * * *     直近投稿の数字を更新（1時間ごと）
        └ 0 20 * * *    日次: 全投稿同期・フォロワー記録・クリック集計・採点・オートパイロット下書き生成
        │
[D1 (SQLite)]  ユーザー / ライセンス / アカウント(暗号化トークン) / 投稿 / 数字 / キュー / 参考情報 / 学習ログ
        │
[外部]  graph.threads.net（Threads API）
        openrouter.ai / generativelanguage.googleapis.com（買い手のキー）
        Resend（メール通知, 無料枠3,000通/月）
```

### なぜCloudflareか
| 候補 | 判断 |
|---|---|
| **Cloudflare Workers + D1 + Cron** | 無料枠が商用OK、Cronが無料、超えても5ドル/月。**採用** |
| Vercel + Supabase | Vercel Hobbyは商用禁止。Supabase無料は1週間放置で停止 |
| GAS | 6分制限・トリガー90分/日・UIがスプシ縛り。今回は不採用 |
| 買い手がセルフホスト | 「Deploy to Cloudflare」ボタンで将来オプション化は可能。初期は不要 |

### 費用（こちら側）
| 項目 | 月額 |
|---|---|
| Workers / D1 / Cron / 静的配信 | 0円（超過時 5ドル） |
| ドメイン | 0円（workers.dev）〜 任意で独自ドメイン |
| メール（Resend） | 0円 |
| AI | 0円（BYOK） |

### セキュリティ
- Threadsトークン・AIキーはAES-GCMで暗号化してD1に保存（鍵はWorkerのSecret）
- AIキーは「オートパイロットOFFの間はブラウザにだけ保存」も選べる（サーバーに預けない）
- ログインはメール＋パスワード＋ライセンスキー。パスワードはPBKDF2/argon2

## 3. 画面構成

### 3-1. 初回 / ログイン
1. ライセンスキー＋メール＋パスワードで登録
2. 「Threadsをつなぐ」：Metaアプリ作成手順（画像付き）→ トークン貼付 → `/me` で検証 → App Secretがあれば60日トークンへ交換 → 完了
3. そのままダッシュボードへ（初回同期は裏で進み、進捗バーを出す）

### 3-2. 共通レイアウト（スマホ前提）
- 左上：ハンバーガー → **アカウント切替**（最大3、設定で上限変更）＋ 画面メニュー
- 右上：**＋ アカウント追加**
- 下部タブ：ホーム / 作る / キュー / オートパイロット / 設定

### 3-3. ホーム（ダッシュボード）
Threadsのインサイトで見られる数字を、期間と指標で切り替えて見る画面。

**期間セレクタ**：7日 / 2週間 / 3週間 / 1ヶ月 / 3ヶ月 / 全期間

**上段KPI**：フォロワー（期間内の増減）／ 表示回数 ／ いいね ／ リンククリック

**グラフ**
- フォロワー推移（日次スナップショット。Threadsに履歴が無いので初回接続日から貯まる）
- 日別表示回数（APIの時系列をそのまま）

**トップ投稿**
- 指標タブ：いいね / 表示 / リンククリック / 返信 / リポスト / 引用
- 期間セレクタと連動
- ツリーは1投稿目に束ねて1行。タップで各段（2投稿目以降）の数字を展開
- 行の操作：「リライト」「リポスト」「これを型にして作る」→ 作る画面へ

**リンク**
- URLごとのクリック数（期間内）。名前を付けて管理。投稿への割り当ては表示回数按分（同一URL複数投稿時）

### 3-4. 作る（投稿作成）

```
┌ 箱1：自分の投稿から ────────────────────┐
│ 過去投稿を検索・指標で並べ替え → 複数選択    │
│ 使い方：「型として使う」／「リライト元にする」│
└──────────────────────────────────────┘
┌ 箱2：参考情報（何個でも） ───────────────┐
│ [＋テキスト貼付] [＋YouTube URL] [＋ファイル] [＋記事URL] │
│  ・YouTube：文字起こしの貼付 or URL（Geminiキーがあれば動画URLを直接読ませる）│
│  ・ファイル：.txt / .md                                    │
└──────────────────────────────────────┘
┌ 指示 ─────────────────────────────────┐
│ 例「箱1の型で、箱2の内容を初心者向けに。コメントにLINE誘導」│
└──────────────────────────────────────┘
        [ 生成する（3案） ]
┌ 結果 ─────────────────────────────────┐
│ 案A / 案B / 案C（タブ）                    │
│ 1投稿目 [編集可]                            │
│ コメント① [編集可]（リンクはここ）           │
│ コメント②…                                 │
│ 「指示で直す」入力 → 再生成（会話形式で履歴保持）│
└──────────────────────────────────────┘
   [下書き保存] [キューに入れる ▸ 今すぐ / 日時指定 / おすすめ枠]
```

- AI設定：OpenRouter（モデル選択）または Gemini（無料枠）。キー未設定なら生成ボタンの代わりに設定誘導
- 生成プロンプトには常に「自分の上位投稿3本（文体の見本）」「500文字」「リンク5本まで」「本文にリンクを置かない（設定）」を含める
- 参考情報は**プール**として保存され、オートパイロットのネタ源にもなる

### 3-5. キュー（投稿管理）
- タブ：予約 / 下書き / 投稿済 / 失敗
- リスト＋カレンダー表示
- 操作：編集 / 複製 / 削除 / 今すぐ投稿 / 日時変更
- 投稿済から：リライト（作る画面へ）/ リポスト（`POST /{id}/repost`）/ 数字を見る
- 失敗はThreadsの返答をそのまま表示（例：リンク5本超過）

### 3-6. オートパイロット
| 設定 | 内容 |
|---|---|
| ON/OFF | アカウントごと |
| 頻度 | 1日1本 / 2本 / 週N本 |
| 時間帯 | 自動（学習結果）/ 固定 |
| ネタ源 | 参考情報プールから選ぶ（ローテーション、使用済みは間隔を空ける） |
| 型 | 自動（学習結果）/ 固定 |
| リンク | リンクプール（LINE・アフィ等）から選ぶ／ローテーション。置き場所は本文 or コメント |
| 承認方式 | ①承認制（通知→OKで出る）②**取消可（既定）**：投稿4時間前に下書きを通知、触らなければ自動で出る ③完全自動 |
| 上限 | 1日の投稿数、深夜帯は出さない、NGワード |

**学習ログ**：「あなたのアカウントでは 警告型 × 21時台 が平均の1.8倍」のように、タグ別の成績を表示。

### 3-7. 設定
アカウント管理（追加・削除・トークン延長・診断）／ AIキー／ 通知（メール・Web Push）／ リンクプール／ ライセンス／ データ書き出し

## 4. オートパイロットの仕組み（差別化の核）

### 4-1. タグ付け
生成した投稿には必ずタグを付ける：
- フック型（呼びかけ / 警告 / 意外性 / 疑問 / 数字 / 断定 / 体験談 / リスト）
- 文字数帯（〜100 / 〜200 / 〜300 / 300〜）
- 時間帯（3時間刻み）× 曜日種別（平日/休日）
- ネタ源ID
- リンクの有無・置き場所

手動で作った投稿・過去投稿も、同じ分類器（ルールベース）で後付けタグ付けする → 学習の母数が最初から確保できる。

### 4-2. 採点
投稿から48時間後（と7日後）に数字を取り、
```
score = 表示回数のアカウント内パーセンタイル × 0.5
      + いいね率（いいね÷表示）のパーセンタイル × 0.2
      + 遷移率（2投稿目÷1投稿目、ツリー時）× 0.2
      + クリック率（リンク時）× 0.1
```
重みは設定で「フォロワー重視 / クリック重視」に切替可。

### 4-3. 選択
次の投稿の「フック型」「時間帯」「ネタ源」を選ぶとき：
- 各タグの平均scoreに事前分布を混ぜる（本数が少ないタグを過信しない）
- 80%：上位タグから選ぶ、20%：試していない組み合わせを選ぶ（探索）
- 同じネタ源・同じ型の連続を避ける

### 4-4. 生成
プロンプト構成：
1. 文体の見本＝自分の上位投稿3本（scoreの高い順、型が違うもの）
2. 今回の型のテンプレ（上位投稿の1行目から抽出した穴埋め）
3. ネタ源の本文（長ければ先頭3,000字）
4. 制約（500文字、絵文字方針、リンク位置、NGワード、禁止表現）
5. 出力形式：JSON（本文、コメント①、コメント②、根拠となる参考箇所）

### 4-5. 安全装置
- 直近30日の投稿と本文が80%以上一致するものは出さない
- 1日の上限、深夜帯除外、NGワード
- 「取消可」モードは通知から4時間の猶予（設定可）
- Threads側の失敗が3回続いたらオートパイロットを自動停止して通知

## 6. Threads API の使い方（このアプリで使う呼び出し）

| 用途 | 呼び出し |
|---|---|
| 接続確認 | `GET /me?fields=id,username,threads_profile_picture_url` |
| 長期化・延長 | `GET /access_token?grant_type=th_exchange_token` / `GET /refresh_access_token` |
| 投稿一覧 | `GET /me/threads?fields=...&limit=100&after=` |
| 自分の返信（ツリー2段目以降） | `GET /me/replies` |
| 投稿ごとの数字 | `GET /{id}/insights?metric=views,likes,replies,reposts,quotes,shares` |
| 日別表示・クリック | `GET /me/threads_insights?metric=views` / `metric=clicks&since&until`（週単位で分割） |
| フォロワー数 | `GET /me/threads_insights?metric=followers_count`（日次で記録） |
| テキスト投稿 | `POST /me/threads?media_type=TEXT&text=&auto_publish_text=true` |
| ツリーのコメント | 同上 ＋ `reply_to_id=<前の投稿ID>` |
| 画像投稿 | `POST /me/threads?media_type=IMAGE&image_url=` → `GET /{container}?fields=status` → `POST /me/threads_publish` |
| リポスト | `POST /{id}/repost` |
| 残り枠 | `GET /me/threads_publishing_limit` |

同期の節約：60日より古い投稿は週1回だけ数字を取り直す（既存ツールと同じ考え方）。

## 7. 買い手のセットアップ導線

1. 購入 → ライセンスキーを受け取る
2. アプリを開いて登録（1分）
3. Metaアプリを作ってトークンを取る（既存マニュアルと同じ手順、約15〜20分。ここだけは省けない）
4. トークンを貼る → 自動で同期開始
5. AIを使う人はOpenRouterかGeminiのキーを設定（Geminiは無料）
6. 参考情報を2〜3個入れて、オートパイロットをON

GAS版より減る手間：スプシのコピー、Apps Scriptのデプロイ、Googleの未検証警告、トリガー設定。

## 9. リスク

- **Threads API の変更**：`clicks` は挙動が揺れる。投稿・返信系は安定。変更履歴を追う前提でアプリ内にバージョン表示
- **YouTube文字起こしの取得**：URLからの自動取得はYouTube側にブロックされることがある。貼付を正とし、URLは「Geminiに動画を直接読ませる」経路を第一候補にする
- **AIの精度（Gemini無料枠）**：文体見本3本＋型テンプレで補う。OpenRouter経由で上位モデルも選べるようにして逃げ道を作る
- **トークンを預かる責任**：暗号化＋「AIキーはブラウザだけに置く」選択肢＋いつでも削除できる導線
- **無料枠超過**：Workers有料化で5ドル/月。売上規模から見て無視できる範囲
