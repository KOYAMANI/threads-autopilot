プライバシーポリシー

◯◯（以下「当方」）は、当方が提供するウェブアプリ「Threads オートパイロット」（以下「本サービス」）における 利用者の情報の取り扱いについて、以下のとおり定めます。

1. 取得する情報

2. 利用の目的

  • 本サービスの提供（ダッシュボードの表示、投稿の予約と実行、オートパイロットの下書き作成）
  • 通知（自動投稿の事前連絡、投稿の失敗、トークンの期限、日次のまとめ）
  • 不正利用の防止（ログイン試行の回数制限、ライセンスの管理）
  • お問い合わせへの対応

3. 第三者への提供

法令に基づく場合を除き、利用者の情報を第三者へ提供しません。本サービスの運営のため、以下の事業者のサービスを利用します。

事業者用途渡す情報
Cloudflare, Inc.アプリの実行環境とデータベース本ポリシー1項のすべて（当方が預けている先です）
Meta Platforms, Inc.（Threads API）投稿の取得と公開アクセストークン、公開する投稿の本文と画像
Resend, Inc.メールの送信メールアドレス、メール本文
Google LLC（Gemini）または OpenRouter, Inc.本文の生成利用者の API キー、生成に使う参考情報と過去の投稿の本文

AI への送信は、利用者ご自身の API キーで行われます。当方は生成の内容を保存しますが（下書きとして）、 AI 提供者側での取り扱いは各社の規約に従います。

4. 保存する期間

  • アカウントと投稿の記録は、退会されるまで保存します
  • 操作の記録（監査ログ）は ◯◯ か月保存します
  • 回数制限のための接続元IPの記録は 1 日で消えます
  • 退会されると、投稿の記録・数字・キュー・参考情報・AIキー・Threads のトークンをすべて削除します。削除の事実だけは、メールアドレスをハッシュ化した形で監査ログに残します

5. バックアップと復旧

データベースは Cloudflare D1 の Time Travel により、直近 30 日間の任意の時点へ復旧できます。 障害時にこの機能で復旧した場合、直近の変更が失われることがあります。

6. 安全管理

  • Threads のアクセストークン、AI の API キー、プッシュ通知の購読情報は AES-256-GCM で暗号化して保存します
  • パスワードは PBKDF2-SHA256（100,000 回）でハッシュ化して保存し、元に戻せる形では保存しません
  • 通信はすべて HTTPS です
  • ログには秘密情報を出力しません

7. 開示・訂正・削除のご請求

ご自身のデータは、本サービスの「設定 → データの書き出し」からいつでも CSV で取り出せます。 削除は「設定 → 退会」から行えます。そのほかのご請求は下記の連絡先へお願いします。

8. Cookie

ログイン状態の保持にのみ Cookie を使用します（sid、HttpOnly / Secure / SameSite=Strict、30 日）。 広告・解析目的の Cookie は使用しません。

9. 変更

本ポリシーを変更する場合、本ページに掲示します。重要な変更は登録メールアドレスへお知らせします。
